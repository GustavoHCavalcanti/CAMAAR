    class Parser::CurrentArgStack

    Stack that holds names of current arguments, i.e. while parsing

    def m1(a = (def m2(b = def m3(c = 1); end); end)); end
                                ^

    stack is [:a, :b, :c]

    Emulates ‘p->cur_arg` in MRI’s parse.y
