    msg(*args) click to toggle source

    Create a new message from a list of messages. Strings are converted to Brakeman::Messages::Plain objects.

    # File vendor/bundle/ruby/3.2.0/gems/brakeman-7.1.1/lib/brakeman/messages.rb, line 5
def msg *args
  parts = args.map do |a|
    if a.is_a? String
      Plain.new(a)
    else
      a
    end
  end

  Message.new(*parts)
end
