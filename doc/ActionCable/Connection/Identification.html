    connection_identifier() click to toggle source

    Return a single connection identifier that combines the value of all the registered identifiers into a single gid.

    # File vendor/bundle/ruby/3.2.0/gems/actioncable-8.1.1/lib/action_cable/connection/identification.rb, line 29
def connection_identifier
  unless defined? @connection_identifier
    @connection_identifier = connection_gid identifiers.filter_map { |id| instance_variable_get("@#{id}") }
  end

  @connection_identifier
end
