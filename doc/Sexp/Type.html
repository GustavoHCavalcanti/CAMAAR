    class Sexp::Type

    Matches anything having the same sexp_type, which is the first value in a Sexp.

    examples:

    s(:a, :b) / s{ t(:a) }        #=> [s(:a, :b)]
s(:a, :b) / s{ t(:b) }        #=> []
s(:a, s(:b, :c)) / s{ t(:b) } #=> [s(:b, :c)]
