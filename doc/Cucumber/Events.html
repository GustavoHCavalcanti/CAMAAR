    module Cucumber::Events

    Events tell you what’s happening while Cucumber runs your features.

    They’re designed to be read-only, appropriate for writing formatters and other output tools. If you need to be able to influence the result of a scenario, use a {RbSupport::RbDsl hook} instead.

    To subscribe to an event, use {Cucumber::Configuration#on_event}

    @example

    InstallPlugin do |config|
  config.on_event :test_case_finished do |event|
    puts event.result
  end
end
